# Лог откликов

Строки добавляет скилл `tailor-cv` со статусом `подготовлено`. Дальше статус ведётся
руками: `отправлено` → `скрининг` / `тестовое` / `собес` / `оффер` / `отказ` / `тишина`.

Зачем: видно, какие формулировки и какие базовые резюме дают отклик, а какие уходят
в тишину. Через 10–15 строк это уже данные, а не ощущения.
