Папка — самодостаточная копия структуры корня, заполненная до конца. Скрипт проверки
находит корень по `profile.json`, поэтому пример работает «как настоящий»:

```bash
python3 ../.claude/skills/tailor-cv/scripts/ats_check.py \
    --pdf applications/2026-07-20_ritm-tech_backend-python/resume.pdf \
    --tex applications/2026-07-20_ritm-tech_backend-python/resume.tex \
    --keywords applications/2026-07-20_ritm-tech_backend-python/keywords.tsv \
    --market rf
```

## Кто это

Алексей Морозов — backend-разработчик уровня Middle, 5 лет опыта, Python и Go.

## Что где смотреть

| Файл | Что демонстрирует |
|---|---|
| `profile.json` | Заполненный профиль: два комплекта контактов, два семейства ролей с `signals` |
| `facts.md` | Банк фактов: ID, уровни, теги, предупреждения `⚠️`, §9 с честными слабыми сторонами, §10 журнал правок |

| `resumes/backend_en.tex` | То же на английском, с контактами международного рынка |
| `applications/2026-07-20_.../` | Полный отклик на вакансию |

## Разбор отклика

Папка `applications/2026-07-20_ritm-tech_backend-python/`:

- `vacancy.md` — сохранённый текст вакансии (вакансии удаляют, это единственная копия);
- `analysis.md` — семейство роли, рынок, **карта «требование → факт-ID»** и список
  пробелов. Главный артефакт: по нему пишется письмо и готовятся ответы на собесе;
- `keywords.tsv` — 21 ключевое слово, `must`/`nice`;
- `resume.tex` / `resume.pdf` — резюме под эту вакансию (база не менялась);
- `ats-report.md` — отчёт проверки, `RESULT: PASS`;
- `cover_letter.md` — сопроводительное с честным абзацем про пробелы;
- `hh_profile.md` — блоки под поля профиля hh.ru.

**Ключевой момент примера.** Вакансия требует ClickHouse и упоминает Terraform.
У Алексея их нет — они в `gap-blacklist.txt`. Поэтому:

1. В резюме их **нет**, хотя это `must`-требование, — `ats-report.md` честно
   показывает `must: 12/13` и предупреждает о непокрытом слове.
2. Отчёт всё равно `PASS`: покрытие информационно, а вот попытка вписать ClickHouse
   уронила бы проверку по blacklist.
3. Пробел закрывается абзацем в сопроводительном — не замалчиванием.

Так система и работает: она мешает соврать, а не помогает.
