\section*{О себе}

% FACT: SUM-backend
Backend-разработчик с 5 годами коммерческого опыта на Python, из них 3 года в финтехе.
Пишу на Python (FastAPI, asyncio) и Go, проектирую \RESTAPI{} и сопровождаю микросервисы
под нагрузкой: платёжный шлюз, над которым работает моя команда, обрабатывает порядка
400 запросов в секунду в пике. Отдельная сильная сторона --- PostgreSQL глубже CRUD:
разбор планов запросов, индексы, партиционирование. Довожу задачи до эксплуатации,
а не до мержа: пишу юнит-тесты, участвую в код-ревью, настраиваю метрики и разбираю
инциденты по своим сервисам.
