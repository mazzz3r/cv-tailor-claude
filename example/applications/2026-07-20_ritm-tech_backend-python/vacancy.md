## О компании

«Ритм Технологии» — платформа для управления складской логистикой. Обрабатываем
заказы и перемещения товара для сетей розничной торговли: около 2 млн событий в сутки.
Команда разработки — 30 человек, backend — 12.

## Задачи

- Разработка и развитие сервисов платформы на Python (FastAPI, asyncio).
- Проектирование REST API для внутренних и внешних потребителей.
- Работа с PostgreSQL: схема данных, оптимизация запросов под растущий объём.
- Участие в декомпозиции монолита на микросервисы.
- Написание тестов, участие в код-ревью, поддержка своих сервисов в проде.

## Требования

- Коммерческий опыт разработки на Python от 3 лет.
- FastAPI (или аналогичный асинхронный фреймворк), уверенное понимание asyncio.
- PostgreSQL на уровне выше CRUD: индексы, планы запросов, оптимизация.
- Уверенный SQL.
- Docker, Linux, Git.
- Опыт построения REST API и работы с микросервисной архитектурой.
- Опыт работы с ClickHouse: у нас на нём построена аналитика по складским событиям.
- Культура тестирования: юнит-тесты обязательны, код-ревью — часть процесса.

## Будет плюсом

- Go: часть сервисов платформы пишем на Go, планируем расширять.
- Kubernetes: сервисы едут в наш кластер.
- Kafka: шина событий между сервисами.
- Redis, gRPC.
- CI/CD (у нас GitLab).
- Prometheus, Grafana — мониторинг на стороне команды.
- Terraform: инфраструктурой команды управляют сами.
