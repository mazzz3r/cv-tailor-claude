# inbox/

Сюда положить всё, из чего скилл `init-cv` соберёт банк фактов:

- старые резюме в любом формате (`.pdf`, `.docx`, `.tex`, `.md`);
- выгрузку профиля hh.ru / LinkedIn;
- список проектов, ссылки на репозитории, дипломы и сертификаты;
- черновики и заметки — что угодно, где есть фактура о вас.

Содержимое папки **не попадает в git** (см. `.gitignore`): здесь лежат сырые личные
документы, а версионировать нужно только вычищенный банк фактов.

После заполнения `facts.md` папку можно очистить — банк фактов самодостаточен.
